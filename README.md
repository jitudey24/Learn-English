# English Janala — English Learning Interface

An English-learning web interface designed to help users explore learning content. The page combines English and Bangla-friendly typography with interactive UI styling.

## Features
- English learning page interface
- English and Bangla font support
- Responsive styling with Tailwind CSS and DaisyUI
- SweetAlert2 integration for alert dialogs
- Remix Icon support

## Technologies
- HTML5
- Tailwind CSS
- DaisyUI
- JavaScript
- SweetAlert2
- Remix Icon
- Google Fonts

## Run Locally
1. Clone this repository.
2. Open `index.html` in a modern browser.
3. Keep the project assets and scripts in their original locations.
4. An internet connection is needed for the CDN-hosted libraries and fonts.

## Project Purpose
This project practices building an educational interface and working with external UI libraries and multilingual typography.
